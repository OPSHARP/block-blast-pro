5. GAMEPLAY RULES, SPECIAL FEATURES, AND VIRTUAL ITEMS

Gameplay Overview:
Block Blast Pro is a strategic block placement puzzle game played on an 8x8 or 9x9 grid. Players arrange geometric block shapes, clear horizontal and vertical lines, generate chain-reaction combo multipliers, and earn scores.

Game Modes:
The Game provides multiple distinct play modes, including:
- Classic Mode: The foundational block puzzle experience with dynamic grid shifts and combo survival.
- Dynamic Grid: An active board system where grid lines dynamically shift in response to board density and combo streaks.
- Heavy Physics: Gameplay featuring weighted blocks with tactile shockwave effects and board pressure.
- Zen Mode: A relaxing puzzle mode without game-over fail states, featuring calming ASMR audio.
- Daily Challenge: A calendar-based challenge scenario generated deterministically each day.
- Blitz Mode: A fast-paced 60-second timed challenge where cleared lines grant bonus time.
- Custom Mode: Player-configurable puzzle boards with adjustable physics and grid settings.
- Journey Mode: A stage-based adventure campaign with level objectives and three-star achievement ratings.
- Rising Lava Mode: A survival challenge where molten lava ascends from the board bottom unless cleared lines push it back.

Special Block Mechanics:
The Game features specialized block pieces, including Anchor Blocks, Gravity Blocks, Magnet Blocks, Pulse Blocks, Void Dissolve Blocks, Bloom Blocks, Split Units, TNT Explosive Blocks, Laser Beam Blasters, Prism Rainbow Wildcards, Tesla Lightning Conductors, Frozen Ice Shells, Treasure Coin Blocks, Time-Bomb Counters, Crystal Geodes, Wormhole Portals, and Morphing Chameleon Shapes.
